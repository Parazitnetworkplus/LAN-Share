## 🚀 How to Run

### Server

1. Run `Server.exe` and keep it open.
2. Open `index.html`.
3. Enter the server computer's IP address.

### Clients

1. Open `index.html`.
2. Enter the server's IP address.

> Port `8000` is added automatically.
> All devices must be connected to the same local network.
> Uploaded files are temporarily stored in RAM and are removed when the server is closed.
> Click **Refresh** after someone uploads a file to see it in the file list.
